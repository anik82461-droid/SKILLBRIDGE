==================================================
CREATE THESE INITIAL API ENDPOINTS
==================================================

1. GET /api/health

Keep the existing endpoint working.

2. POST /api/students

Create a student profile.

Example request:

{
  "name": "Rahul Sharma",
  "email": "rahul@example.com",
  "college": "ABC Engineering College",
  "branch": "Computer Science",
  "year": 3,
  "skills": ["Python", "SQL", "Web Development"]
}

3. GET /api/students

Return the available student profiles.

4. GET /api/students/{student_id}

Return one student.

5. POST /api/skill-match

Request:

{
  "student_skills": ["Python", "SQL", "Java"],
  "required_skills": ["Python", "SQL", "React", "Docker"]
}

Response should contain:

{
  "success": true,
  "data": {
    "match_percentage": 50,
    "matched_skills": ["Python", "SQL"],
    "missing_skills": ["React", "Docker"]
  }
}

The percentage must be calculated by actual backend logic.

Do NOT hardcode the result.

==================================================
SKILL MATCHING RULE
==================================================

For the initial MVP, use a transparent and explainable matching formula:

match_percentage =
(number of matched required skills / total required skills) * 100

Round to the nearest whole number.

Normalize skill comparison so that:

"Python"
"python"
" PYTHON "

are treated as the same skill.

Return both matched and missing skills.
